# Arduino Potentiometer LED Control

A simple Arduino Uno project to control the brightness of an LED using a potentiometer.

About :
In this project, a potentiometer is connected to analog pin A2, and an LED is connected to digital PWM pin 11. The Arduino reads the analog value from the potentiometer (0-1023), scales it down, and uses Pulse Width Modulation (PWM) to adjust the LED's brightness accordingly. 

Components :
* Arduino Uno
* 1 LED
* 1 Resistor 220 Ω (Red-Red-Brown-Gold)
* 1 Potentiometer
* Breadboard
* Jumper wires

Tools :
* Arduino IDE
* C/C++
* Tinkercad Circuits
